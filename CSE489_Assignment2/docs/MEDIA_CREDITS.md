# Audio and video assets

- `res/raw/sample_video.mp4`: Original synthesized landscape animation from the previous Assignment 2 project. Packaged locally for reliable offline playback.
- `res/raw/sample_audio.mp3`: New, original 8-bar calm instrumental arrangement (C-G-Am-F progression) authored for this assignment. Rendered with FluidSynth using the TiMidity `TimGM6mb.sf2` GM soundfont (Copyright 2004 Tim Brechbill and 2010 David Bolton; distributed under GPL-2.0). The resulting MP3 is supplied for this educational project under GPL-2.0. Soundfont source: https://packages.debian.org/timgm6mb-soundfont . The soundfont itself is **not** redistributed here.

The MP3 is a real structured melody with piano, acoustic guitar, flute, pad, and bass, rather than random scattered tone samples. If you prefer a recorded song/voice, replace **only** `app/src/main/res/raw/sample_audio.mp3` with an appropriately licensed MP3 with the same filename; no Kotlin code changes are required.
