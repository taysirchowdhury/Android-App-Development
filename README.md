# Android App Development — CSE489

Android application projects developed for the CSE489 course at BRAC University.

## Assignments

| Assignment | Project | Description |
| --- | --- | --- |
| 1 | [VangtiChai](VangtiChai/) | Kotlin-based Taka denomination calculator with a custom keypad and responsive Android layouts. |
| 2 | [Android Application — Broadcast and Media](CSE489_Assignment2/) | Navigation drawer, Fragments, broadcast receivers, online image zoom, and video/audio playback. |

## Running a project

Each assignment is a separate Android Studio project.

1. Clone or download this repository.
2. Open the relevant assignment folder in Android Studio (the folder containing its own `settings.gradle.kts`).
3. Allow Gradle sync to finish and install any required SDK components.
4. Select an Android emulator or compatible device and run the `app` configuration.
